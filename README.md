# Mesa PCB

Programa web para diseñar plaquetas de una cara, pensado para hacerlas en casa con planchado y percloruro. Sin librerías para descargar: la biblioteca de componentes ya viene incluida.

## Cómo abrirlo

- **En tu compu:** doble clic en `index.html`.
- **En internet:** activá GitHub Pages en este repositorio (Settings → Pages → rama `main`, carpeta raíz). Queda en `https://TU-USUARIO.github.io/mesa-pcb/`.

## Qué incluye

- `index.html`: la mesa de trabajo.
- `huellas.html`: buscador de huellas por nombre de componente.
- `biblioteca/`: 161 componentes de agujero pasante y el programa que los genera.
- `docs/`: investigación sobre reglas de diseño y ruteo automático.
- `CLAUDE.md`: contexto y decisiones del proyecto.
